**Watchmate – Django REST API Project**

Watchmate is a Django-based RESTful web application designed to manage and review movies and streaming platforms. 
It allows users to create, view, update, and delete watchlists, submit ratings and reviews, and associate content with different streaming services. 
The project implements Django REST Framework features such as serializers, class-based views, authentication, and permissions. 
It focuses on clean API design, proper data modeling, and best practices for backend development. Watchmate serves as a practical demonstration of building scalable and secure APIs using Django.
